# Eliane Tur - Landing Page

Site estático (HTML, CSS e JavaScript), pronto para publicar.

## Ver no computador
Abra o arquivo `index.html` no navegador (duplo clique).

## Publicar na Vercel
1. Acesse vercel.com, entre na sua conta e clique em **Add New > Project**.
2. Envie esta pasta (ou conecte um repositório do GitHub com ela).
3. Não precisa configurar nada: a Vercel detecta que é um site estático. Clique em **Deploy**.

## Como atualizar
- **Passeios e valores:** no `index.html`, procure por `PASSEIOS` e edite nome, valores (`p`) e foto (`img`).
- **Fotos:** coloque os arquivos na pasta `imagens/` e ajuste o nome no bloco `IMG`.
- **Logo:** substitua `imagens/logo.webp` (ou .png, ajustando o nome no HTML).
- **WhatsApp:** o número fica na constante `NUM`, no início do script.
- **Instagram:** troque os links `https://instagram.com/` pelo endereço do perfil.
- **Analytics / Search Console:** cole as tags no comentário marcado dentro do `<head>`.
